## Overview 📜

### Solutions.ts

**Contains functions and classes solving 8 practical TypeScript problems**

multiplyValue : Handles optional parameters and explicit zero checking.

processInput : Demonstrates type narrowing for string, number and boolean inputs using union types.

formatCoordinate : Formats a read-only tuple without mutation.

concatenateArrays : Combines multiple array inputs using TypeScript Generics (<T>) and rest parameters.

getPopularCourses : Filters arrays based on interface properties without mutating original data.

pluckValues : Uses generics with keyof constraints to extract specific object properties.

Employee & Manager : Demonstrates OOP concepts including class inheritance, constructor calls using super, and private/protected access modifiers.

validateAgeAsync : Handles asynchronous logic returning a Promise<string> with error rejection for validation failure.
